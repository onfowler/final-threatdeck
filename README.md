# ThreatDeck 🛡️

## What is this?
ThreatDeck is my final project for INST 377. It's a live dashboard that pulls real-time cybersecurity threats (CVEs) straight from the NIST National Vulnerability Database. The goal is to make it easy to track security risks for specific software by using a custom watchlist saved in a Supabase database.

## Supported Browsers
I built and tested this for modern desktop browsers (Chrome, Firefox, Safari, Edge). 
Also works on mobile.
