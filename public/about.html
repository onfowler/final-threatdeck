About ThreatDeck 🛡️

The Project

ThreatDeck was developed as a final project for INST377. It is designed to be a live vulnerability intelligence dashboard that pulls real-time CVE (Common Vulnerabilities and Exposures) data directly from the NIST National Vulnerability Database. The goal is to provide a clean, accessible interface for tracking security threats across specific software assets without getting overwhelmed by raw data feeds.

The Developer

This project was built by Oscar Fowler. As a junior at the University of Maryland (UMD) majoring in Information Science with a minor in Information Risk Management, I wanted to build a tool that bridges the gap between complex government cybersecurity databases and actionable risk management strategies.

Technology Stack

ThreatDeck is built using a Node.js and Express backend, connected to a Supabase PostgreSQL database to manage custom watchlists. The frontend utilizes JavaScript, HTML/CSS, and integrates Chart.js for threat severity visualization.
